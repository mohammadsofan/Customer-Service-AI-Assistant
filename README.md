# ?? Customer Service AI Assistant

An intelligent, Two-Stage RAG-powered (Retrieval-Augmented Generation) knowledge base and ticketing platform designed to empower customer service representatives. Built with a modern **.NET 8 Clean Architecture** backend and a **React 19** frontend, this system allows agents to query complex technical scenarios (e.g., roaming issues, billing) and receive instantaneous, highly-accurate resolution steps generated by AI.

---

## ? Key Features

- **Two-Stage RAG Engine:** 
  - **Stage 1 (Mathematical + Lexical):** Vectorizes telecom knowledge scenarios and queries them using mathematical Cosine Similarity combined with a BM25-lite keyword intersection boost.
  - **Stage 2 (LLM Reranking):** Leverages a semantic reranking prompt to dynamically select the most accurate scenario out of the Stage 1 candidates, virtually eliminating False Positives based on shared keywords.
- **Dynamic Multi-Provider AI:** Seamlessly swap between **Google Gemini**, **OpenAI**, **Groq**, or any OpenAI-compatible API from the admin interface without touching code.
- **Automatic Failover:** Built-in resilience. If your primary LLM provider fails or gets rate-limited during reranking or answer generation, the system automatically routes the query to your configured fallback provider or degrades gracefully.
- **Background Embedding Sync:** Changing your active Embedding Model automatically flags all knowledge vectors as pending, triggering a background worker service to rapidly re-embed the database into the new vector space.
- **Role-Based Portals:**
  - **Admin Dashboard:** Full control over AI Settings (Temperature, Top K, Reranking Settings), Provider management, User management, Analytics, and Scenario CRUD operations.
  - **Employee Portal:** An intuitive chat-like interface for agents to ask questions, view historical answers, and get step-by-step resolutions.
- **Full Arabic Support (RTL):** The UI is completely localized and optimized for Right-To-Left reading.

## ?? Getting Started

### Prerequisites
* **[.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)** installed.
* **[Node.js](https://nodejs.org/)** (v18 or higher) installed.
* **SQL Server** (LocalDB or full Developer edition).

### 1. Database Setup
1. Open src/AIEmployeeSupport.API/appsettings.json (or ppsettings.Development.json).
2. Update the ConnectionStrings:DefaultConnection to point to your local SQL Server instance.
3. Open a terminal in the src/AIEmployeeSupport.API directory and apply the Entity Framework migrations:
   `ash
   dotnet ef database update
   `
   *(This will create the database and seed the default Admin user).*

### 2. Running the Backend
1. Navigate to the API folder:
   `ash
   cd src/AIEmployeeSupport.API
   `
2. Start the server:
   `ash
   dotnet run
   `
   The API will typically be available at http://localhost:5073 or https://localhost:7142.

### 3. Running the Frontend
1. Open a new terminal and navigate to the client folder:
   `ash
   cd client
   `
2. Install the dependencies:
   `ash
   npm install
   `
3. Start the Vite development server:
   `ash
   npm run dev
   `
4. Access the application in your browser (usually at http://localhost:5173).

## ?? AI Configuration Guide

To get the RAG system working, you must configure your AI providers after logging in as an Admin:

1. Navigate to **AI Providers** in the sidebar.
2. Add an LLM provider (e.g., Google Gemini) and provide your API Key.
3. Add the associated models (e.g., gemini-2.5-flash as a generative model, gemini-embedding-2 as an embedding model).
4. Navigate to **AI Configuration** and select your active generative model and active embedding model.
5. Save the configuration. The system will automatically begin generating vector embeddings for all active scenarios in the background!
